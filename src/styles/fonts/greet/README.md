# Greet the World fonts

Copied from [personal-fonts-repo](https://github.com/drSabine/personal-fonts-repo).

- Bebas Neue by Ryoichi Tsunekawa: headings.
- IBM Plex Sans by IBM: instructions, regular and semibold.
- Space Mono by Colophon Foundry: steps, buttons, and detector labels.

Original files are kept unchanged. Each family has its SIL Open Font License beside it. `next/font/local` serves the fonts with the game, so they do not need a font service at runtime.
